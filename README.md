# DxLogRotorController
Custom form for DXLog.net that allows controlling antenna rotators directly from inside DXLog

  - Up to four independent rotator windows
  - Support for Yaesu GS-232 compatible and Prosistel rotators (supplementary protocols can be added by request (for free) as long as the respective protocol is avialable)
  - TCP or Serial connection
  - Clickable compass for selecting the desired heading
  - Manual heading entry
  - Standard heading preset buttons
  - CW, CCW and STOP controls where supported
  - Configurable park position
  - Current and target heading display
  - Optional background map
  - Configurable antenna beam width and display
  - Custom colors and appearance
  - Individual settings and auto-connect for every rotator
  - Custom name for each rotator window
